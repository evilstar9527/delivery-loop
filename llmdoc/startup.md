# Startup：每轮开场阅读清单

## 必读（按序）

1. 执行 `pwd`，确认真实 repo/worktree。
2. [must/project-brief.md](must/project-brief.md)。
3. [must/current-state.md](must/current-state.md)。
4. [../DOD.md](../DOD.md) 当前 Phase。
5. [../PROGRESS.md](../PROGRESS.md) 当前状态、blocker、上一轮遗留。

## 按任务升级

- 找模块/文件 → [architecture/code-map.md](architecture/code-map.md)。
- 改 Task/Run/API/checkpoint/evidence → [../docs/Proto.md](../docs/Proto.md)。
- 改凭证、权限、Action、外部输入或部署 → [../docs/Security.md](../docs/Security.md)。
- 改状态、存储、恢复、队列或外部数据流 → [../docs/Architecture.md](../docs/Architecture.md)。
- 接 GitHub/飞书/tool-bridge/Agent SDK → [../docs/Reference.md](../docs/Reference.md)，并先核实对应外部事实。
- 完成功能或 Phase 关门 → [../LOOP.md](../LOOP.md) 的验证/收尾章节。
